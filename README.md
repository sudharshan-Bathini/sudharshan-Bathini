# 🔭 Projects  

- 🐦 **[Twitter Data Sentiment Analysis](https://github.com/sudharshan-Bathini/Twitter-Data-Sentiment-Analysis)**  
  **Tech Stack:** Python, Scikit-learn, NLTK, Matplotlib  
  🔹 Built an NLP pipeline with TF-IDF feature extraction and achieved **85% accuracy** in tweet classification.  

- 💳 **[Credit Card Fraud Detection](https://github.com/sudharshan-Bathini/credit_card_fraud_detection)**  
  **Tech Stack:** Python, TensorFlow, PyTorch, Keras, Pandas, Matplotlib, Scikit-learn, NumPy  
  🔹 Developed a **hybrid fraud detection system** using **DNNs (TensorFlow)** and **DQNs (PyTorch)**.  
  🔹 Used **Bayesian Optimization** & **SMOTE** for imbalance handling.  
  🔹 Achieved **ROC-AUC: 0.98** & **F1-score: 0.92**.  

- 🤖 **[Chatbot using Cornell Movie Dataset](https://github.com/sudharshan-Bathini/Chat-Bot-using-Cornell-Movie-Data-Set)**  
  **Tech Stack:** Python, TensorFlow, Keras, Pandas, Matplotlib, NumPy, LSTM  
  🔹 Built an **LSTM-based chatbot** for context-aware conversations with NLP preprocessing.
